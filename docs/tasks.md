## 알려진 불확실성

- 공식 API와 공개 웹은 계약이 다르다. 모든 API 기능이 키 없이 재현된다고 보장하지 않는다.
- 파일 목록과 다운로드 권한은 별개다. 실제 접근 거부는 오류로 중단한다.
- 전체 노드링크 ZIP의 실제 전송·CRC·SHA·재사용은 T010에서 검증했다. 전국 링크 완전성을 뜻하지 않는다.
- 자료실 최신 파일을 읽었다고 이전 배포의 권장 사용 공지를 무시하지 않는다.
- 네트워크/환경 실패가 있으면 해당 task를 완료로 바꾸지 않는다.
