## 독립 적대적 리뷰

리뷰 A(`/root/review_a`)는 최초 소스 `e756c6a`에서 A→B→A 복원 후 기본 재사용이 최초
수집시각순의 B를 선택하는 P2를 재현했다. 불변 원본·manifest를 유지하면서 마지막 성공
관찰은 별도 current 포인터와 observed_at으로 원자 공개하도록 수정했다.
최종 SHA에서 다운로드/저장소 테스트73개를 직접 확인했고 기존 P2 해결·추가 P0~P2 없음.

리뷰 B(`/root/review_b`)는 최초 소스에서 manifest 임시 .part가 공개 디렉터리에 있어
동시 reader가 손상으로 오판하는 P2를 결정적으로 재현했다. 임시 manifest와 current를
staging에만 작성한 뒤 최종 경로만 원자 공개하도록 수정했다. 공개 직전 Event로 중단한 동안
별도 Store 조회와 잔여 staging 회귀를 추가했다. Windows 동시 handle로 원자 replace가
잠시 거부되는 경우도 관찰해 파일 worker 내 최대190ms 재시도와 실패 시 이전 선택 유지
회귀를 추가했다. 네트워크 재시도는0회다. B는 최종 오프라인382개를 직접 실행하고
기존 P2 해결·추가 P0~P2 없음으로 통과했다. 외부 context 유지 시 page/session 종료로
CDP 스트림이 회수되는 것도 최초 리뷰에서 독립 확인했다.
