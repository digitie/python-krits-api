## 독립 적대적 리뷰와 수정

리뷰 A(`/root/review_a`)와 B(`/root/review_b`)는 최초 `a79549b`의 XLSX 필수
sheetData 누락/내부 namespace 변경이 정상 빈 표로 반환되는 P2를 독립 재현했다.
정확한 컨테이너1개·row/cell/value namespace·중복을 검사하고 정상 빈 시트와 구분했다.
본문 rich text와 별도 발음 주석도 분리했다.

B는 ZIP 사전검사와 표준 ZipFile의 concat 보정이 다른 directory를 읽는 P2,
S3 종료가 active PUT의 lock 대기 중 취소되면 소유 HTTP client를 남기는 P2도 재현했다.
directory는 EOCD 바로 앞의 정확한 위치만 허용하고, 종료 전체를 별도 task로 추적해
반복 취소에도 정리 완료 후 전파하도록 수정했다. 재리뷰에서는 일반 EOCD sentinel 없이
ZIP64 locator가 다른 directory로 교체하는 변형이 남았다. EOCD 직전 locator를 선제 거부해
ZipFile 객체 생성 전에 같은 경계를 적용했다. 해당 입력의 실제 두 항목 해석과 선제 거부를
모두 회귀로 확인한다.

A/B 모두 `231602b`에서 기존 P2 해결·추가 P0~P2 없음으로 통과했다.
최종 `1424b77`은 runtime이 같고 로컬 live fixture만 정산했다. A는 diff를 재검토했고
B는 실제 Chromium 전송 테스트8개도 재실행해 최종 SHA 통과가 유효함을 확인했다.
