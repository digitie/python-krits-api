## 재조사와 구현 범위

메인 통합지도와 `/js/singlePage` 스크립트, 개별 우회 지도, 통계/위치검색 화면,
5종 공개 사양 페이지를 대조했다. 메인 예측 탭은 조사 시 템플릿 누락으로 정상 노선 렌더링을
확인하지 못했다. 개별 `/map/detour`는 type=fc 노선15건과 날짜·시간·방향별 공개 응답이 작동했다.
UI 함수의 시간 덮어쓰기를 확인하고 같은 페이지의 ajaxRequest에 요청 조건을 정확하게 전달한다.
서버는 날짜/시각을 echo하지 않으므로 scope는 관찰한 요청 조건이며 예측 알고리즘의 정확성 증명이 아니다.

추가 기능은 예측 노선/구간/상세 원문과 예측 본선·VDS·VSL 참고 XLSX4개다.
실시간 VDS 차로 관측과 VSL 가변속도, 주의운전 전용 메시지, 위험물 차량 전용 사고 조회는
재조사한 공개 화면에서 검증할 수 없어 미지원으로 남긴다. 시설물 현황을 실시간 관측으로 바꾸지 않는다.
지원표의10종 부분 지원/파일과2종 미지원은 공식10종 실시간 API 동등성을 의미하지 않는다.

집계 속도/시간이 없는 실제 예측 구간은 None이다. 첫 상세191개 링크의 PASNG_SPED=1은
검증된 예측 속도로 설명하지 않고 raw_speed에 보존한다. 구간 `0401`은 MAIN8/DETOUR17개이며
MAIN 자체 ROAD_NO도1/451로 혼재한다. 상위 조회 노선과 같다고 강제하지 않고 선택 구간ID를 검사한다.
원본·축약 fixture·세부 계약은 [확장 사양](../public-expansion.md)과 [fixture 설명](../../tests/fixtures/README.md)에 있다.
